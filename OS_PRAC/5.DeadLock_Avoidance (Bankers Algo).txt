

#include <stdio.h>

int main()
{
    int n, m;
    int alloc[10][10], max[10][10];
    int avail[10], need[10][10];
    int finish[10] = {0}, safe[10];
    int i, j, k, count = 0, found;

    printf("Enter number of processes: ");
    scanf("%d", &n);

    printf("Enter number of resources: ");
    scanf("%d", &m);

    printf("Enter Allocation Matrix:\n");
    for(i = 0; i < n; i++)
        for(j = 0; j < m; j++)
            scanf("%d", &alloc[i][j]);

    printf("Enter Maximum Matrix:\n");
    for(i = 0; i < n; i++)
        for(j = 0; j < m; j++)
            scanf("%d", &max[i][j]);

    printf("Enter Available Resources:\n");
    for(j = 0; j < m; j++)
        scanf("%d", &avail[j]);

    // Calculate Need Matrix
    for(i = 0; i < n; i++)
        for(j = 0; j < m; j++)
            need[i][j] = max[i][j] - alloc[i][j];

    printf("\nNeed Matrix:\n");
    for(i = 0; i < n; i++)
    {
        for(j = 0; j < m; j++)
            printf("%d ", need[i][j]);
        printf("\n");
    }

    // Safety Algorithm
    while(count < n)
    {
        found = 0;

        for(i = 0; i < n; i++)
        {
            if(finish[i] == 0)
            {
                for(j = 0; j < m; j++)
                {
                    if(need[i][j] > avail[j])
                        break;
                }

                if(j == m)
                {
                    for(k = 0; k < m; k++)
                        avail[k] += alloc[i][k];

                    safe[count++] = i;
                    finish[i] = 1;
                    found = 1;
                }
            }
        }

        if(found == 0)
            break;
    }

    if(count == n)
    {
        printf("\nSystem is in SAFE state.\n");
        printf("Safe Sequence: ");

        for(i = 0; i < n; i++)
            printf("P%d ", safe[i]);
    }
    else
    {
        printf("\nSystem is in UNSAFE state.\n");
    }

    printf("\n");

    return 0;
}

```

## **4. Practical Write-up**

**1. Title:**

Implementation of Deadlock Avoidance Algorithm using Banker's Algorithm.

**2. Aim:**

To implement Banker's Algorithm in C to avoid deadlock and check whether the system is in a safe or unsafe state.

**3. Objectives:**

1. To understand the concept of deadlock avoidance.
2. To implement Banker's Algorithm using C programming.
3. To calculate the Need Matrix from Allocation and Maximum matrices.
4. To determine the safe sequence of processes.

**4. Theory:**

Banker's Algorithm is a deadlock avoidance algorithm used in operating systems. It was developed by Edsger W. Dijkstra. It ensures that resources are allocated to processes only when the system remains in a safe state.

The algorithm checks the availability of resources before allocating them to processes. If a safe sequence exists, the system is considered safe. Otherwise, the system is considered unsafe.

**Important Terms:**

1. **Allocation Matrix:** Represents the number of resources currently allocated to each process.
2. **Maximum Matrix:** Represents the maximum resources required by each process.
3. **Available Resources:** Represents the number of currently available resources.
4. **Need Matrix:** Represents the remaining resources required by each process.

**Need Matrix Formula:**

\\[ Need = Max - Allocation \\]

**Working of Banker's Algorithm:**

1. Accept the number of processes and resources.
2. Enter the Allocation, Maximum and Available matrices.
3. Calculate the Need Matrix.
4. Find a process whose remaining resource requirements are less than or equal to the available resources.
5. Execute that process and release its allocated resources.
6. Repeat the process until all processes finish or no eligible process can be found.
7. If all processes finish, the system is in a safe state; otherwise, it is unsafe.

**Important Syntax:**

```
if(need[i][j] <= avail[j])
{
    // Process can execute
}
```

```
avail[j] += alloc[i][j];
```

The first statement checks resource availability, while the second releases the resources after process completion.
