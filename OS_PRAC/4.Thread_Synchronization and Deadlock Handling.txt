
#include <stdio.h>
#include <pthread.h>
#include <semaphore.h>
#include <unistd.h>

#define N 5

sem_t room;
sem_t fork[N];

void *philosopher(void *num)
{
    int id = *(int *)num;

    printf("Philosopher %d is thinking\n", id);

    sem_wait(&room);

    sem_wait(&fork[id - 1]);
    sem_wait(&fork[id % N]);

    printf("Philosopher %d is eating\n", id);
    sleep(2);

    printf("Philosopher %d finished eating\n", id);

    sem_post(&fork[id - 1]);
    sem_post(&fork[id % N]);

    sem_post(&room);

    return NULL;
}

int main()
{
    pthread_t thread[N];
    int id[N];

    sem_init(&room, 0, N - 1);

    for(int i = 0; i < N; i++)
        sem_init(&fork[i], 0, 1);

    for(int i = 0; i < N; i++)
    {
        id[i] = i + 1;
        pthread_create(&thread[i], NULL, philosopher, &id[i]);
    }

    for(int i = 0; i < N; i++)
        pthread_join(thread[i], NULL);

    for(int i = 0; i < N; i++)
        sem_destroy(&fork[i]);

    sem_destroy(&room);

    return 0;
}

```

## **2. Practical Write-up**

**1. Title:**

Implementation of Deadlock-Free Dining Philosophers Problem Using Semaphores.

**2. Aim:**

To implement a deadlock-free solution to the Dining Philosophers problem using semaphores and understand deadlock and starvation in operating systems.

**3. Objectives:**

1. To understand the concept of deadlock in operating systems.
2. To implement thread synchronization using semaphores.
3. To understand resource allocation among multiple threads.
4. To demonstrate deadlock prevention in the Dining Philosophers problem.

**4. Theory:**

The Dining Philosophers problem is a classical synchronization problem in operating systems. It consists of five philosophers sitting around a circular table. Each philosopher alternates between thinking and eating. To eat, each philosopher requires two forks, one on the left and one on the right.

Since forks are shared resources, multiple philosophers may compete for them simultaneously. Improper resource allocation can lead to deadlock or starvation.

**1. Deadlock:**

Deadlock is a condition in which two or more processes wait indefinitely for resources held by each other. No process can proceed with its execution.

**2. Starvation:**

Starvation occurs when a process waits indefinitely because other processes continuously get access to the required resources.

**3. Semaphore:**

A semaphore is a synchronization mechanism used to control access to shared resources. It uses two basic operations:

- `sem_wait()` – Decreases the semaphore value and waits if the resource is unavailable.
- `sem_post()` – Increases the semaphore value and releases the resource.

Syntax:

```
sem_init(&sem, 0, value);
sem_wait(&sem);
sem_post(&sem);
```

**4. Deadlock Prevention Using Semaphore:**

In this program, a semaphore named `room` is initialized with a value of 4. It allows only four philosophers to compete for forks at a time.

This ensures that all five philosophers cannot hold one fork simultaneously, thereby preventing circular wait and avoiding deadlock.

**Working of the Program:**

1. Initialize five fork semaphores with value 1.
2. Initialize the room semaphore with value 4.
3. Create five philosopher threads.
4. Each philosopher first acquires permission to enter the room.
5. The philosopher picks up the left and right forks.
6. After eating, the philosopher releases both forks.
7. The philosopher leaves the room, allowing another philosopher to enter.

**5. Conclusion:**

Thus, the Dining Philosophers problem was successfully implemented using semaphores. Deadlock was prevented by allowing a maximum of four philosophers to compete for resources simultaneously, demonstrating thread synchronization and deadlock prevention.

**Important viva point:** The room semaphore prevents deadlock, but it does not guarantee starvation freedom. Strict starvation prevention requires additional fair scheduling or queue-based synchronization.
