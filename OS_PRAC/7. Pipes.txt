# **7. Pipes (CO5)**

## **1. C Program: Full Duplex Communication Between Parent and Child Processes Using Pipes**

This program demonstrates full duplex communication using two pipes.

- **Parent Process:** Accepts the pathname of a file and sends it to the child process through the first pipe.
- **Child Process:** Reads the pathname, opens the file, reads its contents and sends them back through the second pipe.
- **Parent Process:** Receives and displays the file contents on standard output.

### **C Program**

```

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <string.h>
#include <sys/wait.h>
#include <fcntl.h>

int main()
{
    int fd1[2], fd2[2];
    pid_t pid;
    char filename[100];
    char buffer[1024];
    int n;
    int file;

    pipe(fd1);
    pipe(fd2);

    pid = fork();

    if(pid < 0)
    {
        printf("Fork failed.\n");
        exit(1);
    }

    else if(pid == 0)
    {
        // Child Process
        close(fd1[1]);
        close(fd2[0]);

        read(fd1[0], filename, sizeof(filename));

        file = open(filename, O_RDONLY);

        if(file < 0)
        {
            char msg[] = "Error: File not found.\n";
            write(fd2[1], msg, strlen(msg));
        }
        else
        {
            while((n = read(file, buffer, sizeof(buffer))) > 0)
            {
                write(fd2[1], buffer, n);
            }

            close(file);
        }

        close(fd1[0]);
        close(fd2[1]);
        exit(0);
    }

    else
    {
        // Parent Process
        close(fd1[0]);
        close(fd2[1]);

        printf("Enter file pathname: ");
        fgets(filename, sizeof(filename), stdin);

        filename[strcspn(filename, "\n")] = '\0';

        write(fd1[1], filename, strlen(filename) + 1);
        close(fd1[1]);

        printf("\nFile Contents:\n");

        while((n = read(fd2[0], buffer, sizeof(buffer))) > 0)
        {
            write(STDOUT_FILENO, buffer, n);
        }

        close(fd2[0]);
        wait(NULL);
    }

    return 0;
}

```

## **2. Practical Write-up**

**1. Title:**

Implementation of Full Duplex Communication Between Parent and Child Processes Using Pipes.

**2. Aim:**

To implement full duplex communication between parent and child processes using two pipes to transfer a filename and its contents.

**3. Objectives:**

1. To understand Interprocess Communication (IPC).
2. To implement communication using pipes.
3. To transfer data between parent and child processes.
4. To read and display file contents using pipe communication.

**4. Theory:**

Interprocess Communication (IPC) is a mechanism provided by an operating system that allows two or more processes to exchange information.

A **pipe** is a communication channel used to transfer data between processes. Pipes generally provide unidirectional communication, so two pipes are required to achieve full duplex communication.

In this program, two pipes are created using the `pipe()` system call.

**1. First Pipe:**

The parent process sends the pathname of the file to the child process.

**2. Second Pipe:**

The child process reads the file contents and sends them back to the parent process, which displays them on the screen.

**Important System Calls:**

| System Call | Purpose                                   |
| ----------- | ----------------------------------------- |
| `pipe()`    | Creates a communication pipe.             |
| `fork()`    | Creates a child process.                  |
| `read()`    | Reads data from a pipe or file.           |
| `write()`   | Writes data into a pipe.                  |
| `open()`    | Opens a file.                             |
| `close()`   | Closes a file descriptor.                 |
| `wait()`    | Waits for the child process to terminate. |

**Important Syntax:**

Creating a pipe:

```
int fd[2];
pipe(fd);
```

- `fd[0]` – Read end of pipe.
- `fd[1]` – Write end of pipe.

Creating a child process:

```
pid = fork();
```

Reading and writing:

```
read(fd[0], buffer, sizeof(buffer));
write(fd[1], buffer, size);
```

**Working of the Program:**

1. Create two pipes using the `pipe()` system call.
2. Create a child process using `fork()`.
3. Parent accepts the filename and sends it through the first pipe.
4. Child reads the filename and opens the file.
5. Child reads the file contents and sends them through the second pipe.
6. Parent reads the contents and displays them on standard output.
7. Both processes close their respective pipe ends.

**5. Conclusion:**

Thus, full duplex communication between parent and child processes was successfully implemented using two pipes. The parent sends the filename, and the child reads and transfers the file contents back to the parent process.
