#!/bin/bash

create()
{
    touch "addressbook.txt"
    echo "Address book file created successfully."
}

insert()
{
    echo "Enter name:"
    read name
    echo "Enter phone_no:"
    read phone_no
    echo "Enter address:"
    read address
    echo "$name | $phone_no | $address" >> addressbook.txt
    echo "Record inserted successfully."
}

view()
{
    if [ -f "addressbook.txt" ]; then
        echo "--- Address Book Records ---"
        cat addressbook.txt
        echo "----------------------------"
    else
        echo "Address book file does not exist yet. Please create it first."
    fi
}

modify()
{
    echo "Enter name that you want to modify:"
    read name
    
    if [ -f "addressbook.txt" ]; then
        grep -v "^$name |" addressbook.txt > addressbook1.txt
        cp addressbook1.txt addressbook.txt
        rm addressbook1.txt
        
        echo "Enter new name:"
        read name
        echo "Enter new phone_no:"
        read phone_no
        echo "Enter new address:"
        read address
        echo "$name | $phone_no | $address" >> addressbook.txt
        echo "Record modified successfully."
    else
        echo "Address book file does not exist."
    fi
}

delete()
{
    echo "Enter name that you want to delete:"
    read name
    
    if [ -f "addressbook.txt" ]; then
        sed -i "/^$name /d" addressbook.txt
        echo "Record deleted successfully."
    else
        echo "Address book file does not exist."
    fi
}
choice=0
while [ $choice -lt 6 ]
do
    echo ""
    echo "1. create"
    echo "2. insert"
    echo "3. view"
    echo "4. modify"
    echo "5. delete"
    echo "6. exit"
    echo "Enter Your Choice:"
    read choice
    
    case $choice in
        1) 
            echo "create file"
            create 
            ;;
        2) 
            echo "insert"
            insert
            ;;
        3) 
            echo "view"
            view
            ;;
        4) 
            echo "modify"
            modify 
            ;;
        5) 
            echo "delete"
            delete 
            ;;
        6) 
            echo "exit"
            exit 0
            ;;
        *) 
            echo "Invalid choice. Please enter a number between 1 and 6." 
            ;;
    esac
done


chmod +x addressbook.sh
./addressbook.sh

4. Theory:
Shell programming is a scripting language used to automate tasks in a Linux operating system. A shell script is a collection of commands written in a file and executed by the shell interpreter. It helps users perform multiple operations efficiently without executing commands individually.

An Address Book Management System is a menu-driven shell program used to store and manage personal contact information such as name, phone number and address. In this program, a text file (addressbook.txt) is used to store records permanently.

The program uses a while loop to repeatedly display the menu until the user selects the Exit option. The case statement is used to execute the operation according to the user's choice.

Operations performed:
1. Create Address Book: Creates a new text file or clears the existing file using the > operator.
2. View Address Book: Displays all stored records using the cat command.
3. Insert Record: Accepts the user's name, phone number and address and stores them using the >> operator.
4. Delete Record: Searches for a particular name using grep and removes the matching record.
5. Modify Record: Removes the existing record and inserts the updated information.
6. Exit: Terminates the program using the exit command.
Important Shell Commands and Syntax:
Command	Purpose
read	Accepts input from the user.
echo	Displays output on the screen.
while	Repeats statements until the condition becomes false.
case	Performs operations based on user choice.
cat	Displays file contents.
grep	Searches for specific text in a file.
mv	Moves or renames a file.
>	Creates or overwrites a file.
>>	Appends data to a file.

Syntax of while loop:
while [ condition ]
do
    statements
done


Syntax of case statement:
case variable in
    1)
        statements
        ;;
    2)
        statements
        ;;
    *)
        statements
        ;;
esac
